# Market Pulse implementation contract

Standalone Python/FastAPI + SQLite app, Vietnamese dashboard, single local operator. No paid AI calls or outbound notifications until configured. API JSON success envelope `{success:true,data:...}`, errors `{success:false,error:...}`. All timestamps ISO UTC, UI displays Asia/Ho_Chi_Minh. No fake news/demo data in production.

## Domain services (owned by services worker)
- `app/news.py`: `DEFAULT_ASSETS` list of dicts `{id,symbol,name,market,aliases:[str]}` (market CRYPTO/VN/US, IDs like CRYPTO:BTC, VN:FPT, US:NVDA); `DEFAULT_SOURCES` list `{id,name,url,market,enabled:true}`.
- `async fetch_feed(source:dict) -> dict`: `{articles:[{title,url,summary,published_at,content_hash}],etag,last_modified}`. Accept source etag/last_modified, validate public HTTPS URL + DNS every redirect; disallow private IP, credentials and unsafe ports; bound response bytes and time. Ignore entries without real timestamps or flag them (do not invent publication time). Conditional 304 returns empty. RSS/Atom + explicit HTML extraction (no arbitrary browser execution). `match_assets(article:dict, assets:list[dict]) -> list[str]`; `event_key(article:dict, asset_ids:list[str]) -> str`; `validate_source_url(url:str) -> str` syntax only; network fetch does DNS security. `async extract_article(url:str)->str` optional.
- `app/ai.py`: `async enrich(article:dict, settings:dict, api_key:str) -> dict` result `{summary,priority:'normal'|'high',verification:'unverified',input_tokens,output_tokens,cost_usd,model}`. No tools; untrusted article delimiters, Pydantic typed output, bounded input/output/retry. Model explicit settings `ai_provider` openai/gemini, `ai_model`, `input_price_per_million`, `output_price_per_million`. Optional pydantic-ai imports. Never fabricate translation when AI off.
- `app/telegram.py`: `async send_message(token:str,chat_id:str,text:str)->str` message id. plain text, bounded length/timeout. No logging secrets or full token URL. Errors safe. Sending only done by engine outbox after explicit UI action/settings.

## Engine/repository (owned by core worker)
- `app/db.py`: `Store(path)` creates schema/seeds assets/sources/config. General public `assets()`, `watchlist()`, `add_watch(asset_id)`, `remove_watch(asset_id)`, `sources()`, `add_source(data)`, `update_source(id,data)`, `delete_source(id)`, `articles(query='',asset_id='',limit=100)` with article asset_ids, `jobs()`, `schedules()`, `save_schedule(data,id=None)`, `delete_schedule(id)`, `settings()`, `save_settings(data)`, `overview()`. Return JSON serializable objects/dicts. `save_settings` contains NO raw secrets. `notifications()` list. `close()` optional. Lock + individual connections or safe sqlite access with transactions.
- `app/engine.py`: `Engine(store, secrets:dict)`, `async start()`, `async stop()`, `enqueue_scan(data)->dict job`, `async tick()` scheduler processing + jobs, `async notify_digest()->dict`, `async test_telegram()->dict`, `async run_schedule(id)->dict`. Persist queued jobs/outbox, recover interrupted jobs, serial single-instance worker, dedupe requests. Engine passes secrets['ai_api_key'], secrets['telegram_bot_token']; NOT persisted in store.
- Scan body `{asset_ids:[str],hours:24,source_ids:[],force:false,notify:false}`, default watchlist, hours 1..168; no source_ids means enabled sources. Job `{id,status:'queued'|'running'|'completed'|'failed',stage,created_at,finished_at,stats:{fetched,matched,new,duplicates},error}`.
- Article `{id,title,url,summary,published_at,first_seen_at,source_name,asset_ids:[str],priority,verification,ai_enriched:bool,event_key}`. Cached title/link/feed excerpt clearly labeled; news content stays inert.
- Schedule `{id,name,asset_ids:[str],source_ids:[],cron:'*/30 * * * *',timezone:'Asia/Ho_Chi_Minh',hours:24,notify:false,enabled:true,next_run_at,last_run_at}` croniter 5-field + ZoneInfo validation. Prevent overlapping runs. Missed slots coalesce to one, no catch-up storm. Allow daily cron digest by `kind:'scan'|'digest'` (default scan).
- Settings defaults `{ai_enabled:false,ai_provider:'openai',ai_model:'',daily_budget_usd:0.5,monthly_budget_usd:10,input_price_per_million:0,output_price_per_million:0,telegram_enabled:false,telegram_chat_id:'',notify_high_only:true,max_notifications_per_day:10,quiet_start:'22:00',quiet_end:'07:00',timezone:'Asia/Ho_Chi_Minh'}`. Budget reserve before calls with configured price; require nonzero prices/model/key to enable AI. Track cost/tokens for failed calls conservatively. Model cap max output 500 tokens; reserve input worst-case 12000 tokens. No unlimited automatic retry. Day/month based UTC documented.
- Overview `{article_count,source_count,watch_count,active_schedules,usage:{input_tokens,output_tokens,cost_today,cost_month,calls},last_scan_at,ai_configured,telegram_configured}` plus optional fields. Store usage rollups; runtime readiness booleans supplemented by API secrets.

## HTTP API (owned by root)
- GET `/api/session` returns `{authenticated,csrf}` (csrf when authenticated). First start generates local access password shown once in startup console and persisted restrictive-permission local data file. Login POST `/api/login` `{password}`, logout POST; HttpOnly SameSite strict session cookie, Origin/Host validation + X-CSRF-Token mutation guard, default localhost bind only. Rate limit API/login.
- GET `/api/overview`, `/api/assets`, `/api/watchlist`, `/api/sources`, `/api/articles?q=&asset_id=`, `/api/jobs`, `/api/schedules`, `/api/settings`, `/api/notifications`.
- POST `/api/watchlist` `{asset_id}`; DELETE `/api/watchlist/{id}`.
- POST `/api/scans` scan body (202), POST `/api/schedules/{id}/run`.
- POST `/api/sources` `{name,url,market:'ALL'|'CRYPTO'|'VN'|'US',enabled:true}`; PATCH `/api/sources/{id}`; DELETE.
- POST `/api/schedules` schedule body; PUT `/api/schedules/{id}`; DELETE.
- PUT `/api/settings` settings body (partial allowed); optional write-only `ai_api_key`, `telegram_bot_token` persisted encrypted by root with cryptography Fernet in local data dir; API returns `ai_key_configured`,`telegram_token_configured` booleans only. Empty key means keep existing. Separate explicit `clear_ai_key`, `clear_telegram_token` flags.
- POST `/api/notifications/test` and `/api/notifications/digest`.
- UI vanilla HTML/CSS/ES modules in web/, served same origin; no CDN/dependency build step. Views Overview, Scan, Watchlist, Schedules, News, Sources, Notifications, Settings/Usage. Always render untrusted text via textContent/escape; safe links only https/http; no inline JS for CSP. Poll jobs/overview only when logged in. Responsive light editorial financial dashboard with teal accents, Vietnamese copy, rich empty/loading/error states and accessible labeled forms. No stock-price widgets because not price service. CRUD working, settings secrets write-only, login panel.

## Tests
Each worker writes tests before implementation and reports a red run, then green. pytest + pytest-asyncio + httpx + pytest-cov. Tests offline mocked external services. Root handles HTTP integration and browser E2E. All writes confined to apps/market-pulse. Do not change other workers' files or unrelated ECC files.
